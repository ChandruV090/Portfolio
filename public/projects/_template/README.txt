TEMPLATE — folders starting with "_" are ignored by the site.

To add a project:
  1. Copy this whole folder and rename it, e.g.  food-delivery-app
     (the folder name becomes the page address:  /work/food-delivery-app)
  2. Drop your images / videos into it:
        cover.png  (or cover.mp4)   → the tile on the home page
        1.png, 2.png, 3.mp4 ...      → the case-study page, shown in name order
        poster.jpg  (optional)       → preview frame for a cover video
  3. Edit info.json.

size:     "s" small · "m" medium · "l" large · "tall" · "wide" (full width)
category: any word you like ("products", "design", "branding"...) — the filter at the top builds itself from these.
Video:    MP4 (H.264), under ~10 MB each works best. GitHub rejects single files over 100 MB.
